# Lucid Digging

**Unity 2D Action Roguelite | AI-Assisted Refactoring & Gameplay Improvement**

## 프로젝트 소개

Lucid Digging은 약 3일 동안 게임 개발 과제로 제작한 Unity 기반 2D 액션 로그라이트 프로토타입을 **OpenAI Codex(AI Agent)를 활용하여 리팩터링하고, 게임플레이와 시스템 구조를 개선하는 프로젝트**입니다.

초기 과제에서 구현한 기능을 기반으로 조작감, 전투 시스템, 성장 시스템 및 게임 연출을 단계적으로 개선하고 있습니다.

## 프로젝트 목표

- 기존 프로토타입의 문제점 분석 및 코드 구조 개선
- 플레이어 이동과 전투 조작감 개선
- Run 기반 경험치 및 랜덤 강화 시스템 확장
- 무기·스킬 시스템의 전략적 선택지 강화
- 몬스터와 보스의 전투 피드백 개선
- AI Agent를 활용한 개발 워크플로우 및 검증 과정 정립

## AI Agent 활용 방식

이 프로젝트에서는 **개발 방향의 결정과 최종 검증은 개발자가 담당하고, Codex는 코드 분석과 구현을 지원하는 방식**으로 작업합니다.

1. **문제 정의:** 직접 플레이하면서 문제점을 발견하고 개선 목표를 설정합니다.
2. **코드 분석:** Codex가 관련 코드의 구조와 원인을 분석합니다.
3. **개선안 검토:** 수정 범위, 기존 기능과의 충돌 가능성, 테스트 방법을 검토합니다.
4. **구현:** 승인된 기능에 한정하여 Codex가 코드를 수정합니다.
5. **검증:** Unity에서 직접 플레이하며 정상 동작과 조작감을 확인합니다.
6. **버전 관리:** 검증된 변경 사항을 Git 브랜치와 Commit으로 관리합니다.

AI가 코드를 생성하는 것 자체보다, **AI의 작업 범위를 관리하고 결과를 검증하는 과정**에 중점을 둡니다.

## 주요 개선 작업

### 완료

- 대각선 방향 입력 정확도 개선
- 입력 시차 및 잔여 입력으로 인한 오작동 완화
- 연속 이동 반복 간격 조정
- 공격·이동 애니메이션 완료 시점에 따른 행동 잠금 개선
- 공격 애니메이션 타이밍 조정
- Run 단위 경험치 및 레벨 관리 시스템 구현
- 적 처치 경험치 중복 지급 방지 및 다중 레벨업 처리

### 진행 예정

- 레벨업 시 랜덤 강화 카드 3장 선택
- Run 한정 능력치 및 스킬 강화
- 채굴·전투 무기 구분
- 지형·몬스터 피격 피드백 개선
- 보스 패턴 및 연출 개선
- 게임 밸런스 조정

## 기술 스택

- **Engine:** Unity
- **Language:** C#
- **Animation:** DOTween
- **Version Control:** Git / GitHub
- **AI Agent:** OpenAI Codex

## 프로젝트 진행 방식

기존 과제로 제작한 프로토타입은 `main` 브랜치에 보존하고, 기능 개선 작업은 별도 브랜치에서 진행합니다.

각 기능은 분석 → 구현 → 플레이 테스트 → Commit 순서로 관리합니다.

이 저장소는 완성된 게임의 배포보다는, **기존 프로토타입을 개선하는 개발 과정과 AI 협업 방식을 기록하는 데 목적**이 있습니다.
